# PUMA-themed sales learning package

Begin with `PUMA_Complete_Handbook.html`, which opens in a browser without an internet connection. It contains the entire dataset explanation, 140-step Excel foundation, 125-step advanced Excel dashboard build, 34 SQL exercises, 20 Python sections and answer checks.

Keep all folders together after extracting. Use the starter workbook and starter database for your own work. The solution workbook, database, executable scripts, notebook and completed result tables are supplied for comparison.

Published PUMA group sales are provided separately in `data/puma_published_sales_2023_2024.csv`. All transaction data, customers, products, prices, costs, deliveries and targets are simulated and do not reconcile to PUMA reported turnover.

Excel: `excel/PUMA_Sales_Starter.xlsx`.
SQL: `sql/puma_starter.sqlite`, then `01_setup_views.sql`, then one query at a time from `02_analysis_queries.sql`.
Python: `python/puma_analysis.ipynb`, or run `python python/puma_analysis.py` from the package root after installing pandas, numpy and matplotlib.

Standalone chapter files are under `guides`. Expected controls and completed reports are under `results`.
